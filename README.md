# دیمۆی Smart-Serve POS (براوسەر)

ئەم فۆڵدەرە **تەنها UIی POS**ـە. `server/` و `electron/` و `market.db` تێدا نییە. داتای فرۆشگای ڕاستەقینە لێرەدا نییە.

## GitHub + Vercel

1. ڕیپۆ: `basamdev/smartserve-pos-demo`
2. Vercel ئەم فۆڵدەرە وەک Root Directory دەبڵاو دەکاتەوە.
3. چوونەژوورەوە: بەڕێوەبەر `demo` / PIN `0000` — کاشێر `cashier` / PIN `0000`.
4. دوای چوونەژوورەوە **داشبۆرد و هەموو پەڕەکان** دەردەکەون (کاڵا، پسووڵە، کڕیار، بەکارهێنەر، ڕێکخستن، کاشێر).

چوونەژوورەوە: بەڕێوەبەر `demo` / PIN `0000` — کاشێر `cashier` / PIN `0000`.

## سنوور

- کار دەکات: سکان (تایپ/کامێرا)، سەبەتە، پارەدان، داشبۆرد، قەرز، خەرجی، ڕێکخستن.
- کار ناکات وەک دێسکتۆپ: چاپکەری 80mm، کشۆی پارە، سکانەری USB وەک لە کاشیر.
- هەر براوسەرێک کۆگای خۆی هەیە (localStorage). دوگمەی «گەڕانەوە بۆ سەرەتا» دیمۆ پاک دەکاتەوە.

## wasm

فایلی `js/sql-wasm.wasm` دەبێت وەک `application/wasm` بگات. `vercel.json` ئەوە دادەنێت.

## تاقیکردنەوەی ناوخۆیی (نەک ڕێگای سەرەکی)

- `start-demo.bat` یان `npx serve -l 4173 .`
- یان فۆڵدەرەکە بخە ناو XAMPP `htdocs` و `http://localhost/demo/` بکەرەوە.
- **`file://` مەکەرەوە** — sql.js/wasm زۆرجار کار ناکات.

فرۆشتنی ڕاستەقینە: `smartServe-marketPos Setup 1.0.0.exe`.
